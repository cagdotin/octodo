# Source playbooks

The **why** skill searches each evidence source octodo has. Each source has one playbook below.

| Source              | Playbook                                               | What it covers                                                  |
| ------------------- | ------------------------------------------------------ | --------------------------------------------------------------- |
| Source control      | [`code-archaeology.md`](./sources/code-archaeology.md) | git history, `gh` PRs and issues, in-repo comments and tests    |
| Task tracker        | [`octodo-tasks.md`](./sources/octodo-tasks.md)         | `.octodo/` task files, their frontmatter, and their git history |
| Long-form docs      | [`docs.md`](./sources/docs.md)                         | `docs/`, `AGENTS.md`, `README.md`, skills                       |
| Past agent sessions | [`agent-sessions.md`](./sources/agent-sessions.md)     | this workspace's transcripts in the harness's session store     |

Not available yet: infrastructure observability, error tracking, product analytics. Add a playbook here when one exists.
