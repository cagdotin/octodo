One brain, many arms

You decide. Every arm can do the work.

Most of an octopus's neurons live in its arms, and each arm acts on its own while one brain keeps them in step. octodo works the same way: you plan, and the app, the terminal and your agents all work through one set of tasks.

A calm, fast app

Lists, Today, Next 7 days, priorities and due dates on the desktop. Open the same app on your phone over Tailscale.

Your agents, built in

A built-in MCP server lets Claude Code and other agents read the backlog, create tasks and move them along. octo skills export teaches a project's agents how.

A terminal arm

octo creates, lists and moves tasks without leaving the shell, with --json when a script needs it.

Plain ink

The files are the database.

Every task is a markdown file with a little frontmatter, kept in a .octodo/ folder next to your project. Nothing is locked away, and there is nothing to export.

  • Folders are statuses. Moving a task to Done moves its file.
  • Edit by hand anytime. Your editor, grep and the app all stay in step.
  • Sync the way you already do. iCloud, git or anything else that moves files. Writes are atomic, so they never see half a file.
  • Local first. Your tasks stay on your machine.

Get started

Eight arms for your to-dos.

Point octodo at a project folder and start writing. The desktop app for macOS is on its way; until then, the CLI runs the whole thing.

~/code/my-project 
$ octo init .                        # create .octodo/
$ octo create "First task" -p high
$ octo list
$ octo move MP-1 in-progress
$ octo serve                         # app, API and MCP
$ claude mcp add octodo -- octo mcp  # give your agents an arm
